# Логування будь-якого процесу

## Вміст і запуск

У ZIP є тільки файли `.sql`: таблиці, пакети, `Scripts/install.sql` та `Tests/`. Цей README лежить поряд з архівом у папці проєкту. Паролі та налаштування підключення не включено.

Підключіться до цільової схеми через SQLcl або SQL*Plus і запустіть `@Scripts/install.sql`, потім відповідний файл із `Tests/`. Для перегляду результатів увімкніть `SET SERVEROUTPUT ON`. Наявні навчальні таблиці `EMPLOYEES`, `JOBS`, `DEPARTMENTS` та необхідні права мають бути доступні.
